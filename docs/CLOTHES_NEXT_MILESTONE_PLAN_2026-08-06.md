# 服装下一阶段实验计划

日期：2026-08-06

当前基线：`clothes_test` 分支提交 `c060b62`。无袖背心已经完成一次可复现的
Actor 适配、Surface Deform、四方向八动作帧渲染和适配检测，但它只证明了躯干
无袖服装链路，不代表袖子、裤子、鞋子或盔甲已经解决。

## 总原则

1. 每次只引入一种新服装结构，不把多个新部件混在同一轮。
2. 失败候选只保留在本地实验目录，不覆盖 Gallery current。
3. 每件服装都必须通过静态、动作、遮挡和四方向检查，才允许进入后续随机池。
4. 随机化只选择已经通过验收的整体服装包，不随机拼接未经验证的局部网格。

## 实验顺序

### 0. 无袖背心基线——已完成

- 记录 Actor 骨骼、躯干深度切片、下摆和肩部参数。
- 使用 Physics Proxy + Render Garment + Surface Deform。
- 通过四方向 × 8 动作帧适配检测。
- 作为所有后续服装的回退版本。

### 1. 短袖上衣——当前实验

目标是验证袖窿、袖筒和上臂跟随，不追求复杂褶皱。

首轮只做简单短袖：躯干沿用已通过的无袖基线，袖筒作为连续独立网格连接到
袖窿；袖口落在上臂中段，不覆盖肘部、前臂和手。

必须记录的参数：

- 左右锁骨尾部、上臂骨骼头部：袖窿和肩部上缘；
- 上臂骨骼长度：袖口高度；
- 上臂局部切片：袖筒的前后深度和横向半径；
- 腋下切片：袖筒与衣身的连接宽度；
- 袖口 clearance：袖口与手臂表面的间隙。

验收重点：袖口不能包住手，袖筒不能悬浮或穿过上臂，手臂摆动时袖筒必须跟随
上臂，腋下不能出现撕裂或三角缺口。

### 2. 裤子——短袖通过后进行

首轮只做短裤或简单双腿裤，不同时处理口袋、裙摆和宽松褶皱。

必须分别采样：腰线、骨盆、左右大腿根、大腿中段、膝盖和裤脚。裤子不能复用
上衣的单一前后深度参数。

验收重点：裆部连续、左右裤腿不互穿、大腿抬起时不穿出裤脚、裤脚不悬浮，且
不能把脚和另一条腿错误纳入同一权重区域。

### 3. 鞋子——作为独立配件实验

鞋子可以应用同一套总体工作流：资源登记 → Actor 锚点适配 → 动作绑定 →
四方向渲染 → 检测 → Gallery 审核，但不能直接套用上衣的 Surface Deform 和
躯干深度规则。

首轮建议做刚性低帮鞋或短靴：鞋体绑定到左右脚骨骼，鞋底、鞋尖和脚踝作为
独立局部参数；不引入布料模拟。软靴或袜子才考虑 Surface Deform。

鞋子需要额外记录和检测：

- 左右脚、脚踝、脚尖骨骼的实际名称和方向；
- 鞋底高度、鞋尖方向、脚背覆盖和脚踝开口；
- 鞋底与地面的接触，不能穿入地面或悬浮；
- 左右鞋不能互换，行走时鞋尖不能翻转；
- 脚部遮挡关系不能露出明显的赤脚网格。

因此，鞋子是可行的，但应作为 `rigid_footwear` 配件类别单独实现，不把它当作
`soft_garment` 的缩小版。

### 4. 盔甲

盔甲采用刚性骨骼锚点、分件碰撞和硬边轮廓验收。它不与软布料共享松弛量、
布料平滑或褶皱规则，放在基础上衣和裤子之后验证。

### 5. 受约束随机化

至少完成一件通过验收的短袖、一件裤子和一件鞋子后，再建立随机化池。每个
服装包保存类别、覆盖槽位、互斥组、支持体型、材质和可复现 seed。运行时只
随机选择通过验收的整体包，离线 Gallery 负责审核具体 seed。

## 每轮固定流程

1. 记录输入资源、许可证、单一变量和参数来源。
2. 在独立实验目录生成候选，不覆盖 current。
3. 运行 Blender 后台渲染四方向 × 8 帧。
4. 运行服装适配检测器，并记录最差帧和顶点坐标。
5. 通过后更新 Gallery current；失败候选只写入实验记录。
6. 通过人工审核后再提交、推送和进入下一阶段。
