# Character Anchor 轮廓合同

## 当前唯一概念基准

当前角色外观与轮廓以项目根目录的
`front-character-anchor.png` 为准。它是带发型、披风/服装、手部和靴子轮廓的正面角色设计锚点，不再使用 `base-mannequin-4way-female-sheet.png` 作为当前目标。

`front-character-anchor-female.png` 是女性表现变体；只有在明确选择女性变体时才使用它。当前任务指定的是无后缀的 `front-character-anchor.png`。

## 轮廓验收重点

- 大头比例保留，但头部不能压扁或侵入肩颈；
- 发型外轮廓、披风/肩部轮廓、衣摆和靴子是整体剪影的一部分；
- 双臂和手掌要从披风与躯干中分离出来；
- 腰带、衣摆和短裤/腿部层次要保持清晰的上下关系；
- 正面是当前第一道硬门槛，四方向扩展要继承同一套头身比例和服装体块；
- 五官、材质高光和服装内部纹理暂不作为第一轮验收条件。

## 淘汰样本规则

之前对照板中列出的 `chibi_base_mesh_actor_v2`、`head_scale=0.85` 和身体加宽试拍，全部是已淘汰的 3D 技术样本。它们只能作为失败记录，不能作为候选演员、轮廓参考或运行时资源来源。

当前 `chibi_eyes_ears_walk_v1` 用于验证“渲染 → 像素化 → Godot”流程，不代表它符合本概念锚点。

## 下一步

先寻找或制作一个能在正面轮廓上接近 `front-character-anchor.png` 的中性 3D 演员，再把四方向动作迁移到该演员。只有正面静态轮廓通过后，才继续四方向渲染和像素化。
