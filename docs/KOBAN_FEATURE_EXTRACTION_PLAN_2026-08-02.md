# Koban 五官提取与原演员随机化方案（2026-08-02）

## 目标

使用下载的 Koban 模型提供眼睛、眉毛和耳朵的风格基准，但保留项目原有演员的身体、骨架和走路动作：

`Koban 五官风格 → 独立基础五官资产 → 挂载到原演员 CC_Base_Head → 受约束随机化 → 四方向渲染 → 像素化`

不采用 Koban 整个身体直接替换原演员的方案。

## 已确认的模型条件

推荐使用：

`prototype/assets/external/koban_chibi_base_mesh/Koban Chibi Base Mesh VRM export.blend`

该文件包含：

- 1 个角色网格；
- 1 个骨架；
- 70 个骨骼顶点组；
- 眼睛颜色、瞳孔/轮廓、耳朵内层等材质分组；
- `eyes blink`、左右眨眼、视线、眉毛、`eye size` 等 Shape Keys。

由于 Koban 的脸部是一个网格，不能假设眼睛、眉毛、耳朵已经是独立 Object。第一次需要在 Blender 中按材质和连通面选择进行拆分，并检查是否有皮肤面被一并选中。

## 资产分层

### 基础五官基准

先只制作一套固定基准：

- `eye_outer`：浅层眼睛外壳/眼白；
- `iris_pupil`：虹膜和瞳孔；
- `eye_highlight`：高光；
- `brow`：眉毛浅层网格或曲线；
- `ear_outer`：耳朵外层；
- `ear_inner`：耳朵内层。

鼻子和嘴巴暂不加入随机五官系统。未来装饰也作为独立挂点，不混入五官随机种子。

### 随机参数

随机化必须是“受约束的风格变体”，不是任意噪声：

- 眼睛：预设形状、宽高、间距、倾角、虹膜颜色、高光数量；
- 眉毛：直线/弧线/粗细、角度、与眼睛的距离；
- 耳朵：圆耳/尖耳、大小、旋转、耳根高度、内层颜色；
- 全局：统一缩放和整体脸部锚点偏移。

每个角色只生成一次 `appearance_seed`，四方向和所有动画帧复用同一组参数，保证外观一致。

## 挂载规则

所有独立五官资产放入一个 `FaceFeatureRoot`，再挂到原演员的 `CC_Base_Head`。提取后的 Koban 局部网格需要经过：

1. 局部原点归一化；
2. 按原演员头部宽、高、前表面深度重新缩放；
3. 对齐眼睛基准线、耳根高度和头部朝向；
4. 绑定或父子约束到 `CC_Base_Head`；
5. 检查正面、侧面、背面是否出现穿模或漂浮。

## 实施顺序

1. 从 Koban 拆出一套固定基础眼睛、眉毛和耳朵；
2. 在原演员上做静态四方向对齐；
3. 做头部动画/走路动画下的跟随测试；
4. 把基础资产接入随机参数和种子；
5. 对随机变体做自动边界、相互遮挡和四方向一致性校验；
6. 通过后才接入正式四方向像素资源包。

## 当前结论

这条路线可行，而且比当前程序化球体五官更符合目标。最大的技术风险是 Koban 单网格拆分时的面选择和原演员头部比例差异；这两个风险可以通过一次性拆分工具和显式锚点参数控制，不需要重新更换整个演员。
