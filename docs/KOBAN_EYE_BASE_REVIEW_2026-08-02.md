# Koban 风格眼睛基准评审（2026-08-02）

## 结论

Koban 的原始眼睛可以作为风格、配色和比例参考，但不直接把提取出的整块眼部网格作为原演员的最终眼睛。

原因是原始眼岛包含多层内部面，沿侧面观察时厚度约为 `0.345`，而正面可见高度约为 `0.36`。这会让眼睛像一整块厚几何体贴在脸上，并在侧视出现尖角、断面和过度突出。

当前采用的方案是：

1. 保留 Koban 的黑色轮廓、白色眼白、绿色虹膜和黑色瞳孔配色。
2. 使用 Koban 提取眼睛的中心、宽高作为比例输入。
3. 重新生成薄型分层动漫眼：黑色杏仁形眼眶、白色眼白、浅凸虹膜、瞳孔和高光。
4. 让眼睛前后厚度保持在约 `0.10`，并通过 `--eye-inset` 控制与演员脸部表面的贴合深度。
5. 眉毛和耳朵暂时继续使用提取网格；耳朵仍处于单独修形阶段。

## 当前测试参数

```text
eye_style=anime_plate_v2
front_offset=0.18
ear_outward=0.10
eye_inset=0.09
```

测试命令：

```powershell
.\tools\run_koban_feature_attachment_test.ps1
```

可调参数：

- `-EyeInset`：数值越大，眼睛越向头部内部收回；当前 `0.09`。
- `-FrontOffset`：整体五官相对头部锚点向前移动的量。
- `-EarOutward`：耳朵向左右外侧移动的量。
- `-EyeStyle source`：保留原始提取眼睛，仅用于对照，不作为当前推荐方案。

## 评审结果

`anime_plate_v2` 已通过四视图文件和尺寸校验：

- 正面：眼睛轮廓更接近动漫杏仁形，虹膜、瞳孔和高光分层可见。
- 侧面：不再显示原始厚眼岛的大面积侧壁，眼睛前沿收回到演员头部轮廓附近。
- 背面：没有把眼睛错误带到头部后方。
- 当前限制：严格侧视仍会看到眼睛的窄边，这是薄型 3D 眼片的预期表现；下一步需要在头部动画和 3/4 视角中继续确认，不应直接宣称最终美术完成。

## 下一步

1. 用 `EyeInset` 在 `0.07–0.11` 范围测试，确定不同头部姿态下的安全区间。
2. 评估眉毛与新眼睛的间距是否需要联动缩放。
3. 修整 Koban 耳朵提取区域，再把眼睛、眉毛、耳朵统一放入可随机化的 `FaceFeatureRoot`。
4. 静态四视图稳定后，再做 `CC_Base_Head` 骨骼跟随和四方向行走测试。
