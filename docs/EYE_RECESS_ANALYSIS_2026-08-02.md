# Miku 与演员眼部内凹结构分析（2026-08-02）

## 结论

Miku 的眼球本身仍然是凸出的球面；“动漫眼睛往里凹”的视觉效果主要来自三层关系：

1. 头部/眼眶表面形成眼睛开口和外轮廓；
2. 眼球整体位于眼眶表面之后；
3. 眼睑、眼眶边缘和睫毛遮挡眼球边缘，使眼球不会像贴在脸上的完整椭圆球。

## 已测量的深度关系

- Miku `head_org_0_0_node` 前表面约为 `Y=-57.8249`。
- Miku `eye_007_22_0_node`（眼眶/眼部皮肤轮廓）前表面约为 `Y=-57.8247`，基本位于脸部表面。
- Miku `eyeball_1_0_node` 前表面约为 `Y=-42.4709`，比眼眶表面后退约 15.35 个源模型单位。
- 当前演员头部正面约为 `Y=-0.72`；`MikuChibiEyeball` 前表面约为 `Y=-0.6709`，在眼睛区域只形成很小的后退量，同时没有演员适配的眼眶/眼睑遮挡层。

因此当前问题不是单纯缩放眼球，而是缺少“演员脸部上的眼眶开口层”。

## 推荐实现顺序

1. 保留当前 Miku 虹膜眼球作为视觉核心；
2. 制作左右独立的演员适配眼眶环/眼睑层，投射到演员头部表面；
3. 将眼球沿头部内侧方向后移，使其被眼眶边缘部分遮挡；
4. 再把睫毛作为眼眶上缘的独立网格贴合到脸部；
5. 输出正面、侧面和 64 像素预览，确认没有悬浮和穿模。

## 暂不推荐

直接对演员头部做 Boolean 大洞。它可能破坏头部拓扑、材质和后续骨骼变形。对于我们的 3D 渲染到像素资源流程，优先采用“眼球 + 眼眶环 + 睫毛”的分层结构，足以得到 Miku 类似的内凹视觉效果，也更容易随机化和维护。
