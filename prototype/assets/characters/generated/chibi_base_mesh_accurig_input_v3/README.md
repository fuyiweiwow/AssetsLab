# Chibi Base Mesh AccuRIG Input v3

Use this FBX for the external rigging test:

`chibi_base_mesh_accurig_input_v3.fbx`

The source archive is a right-half mesh with a Mirror modifier. This package
applies the Mirror modifier at the original source plane, applies Subsurf, and
only then centers the completed model. It contains one mesh and no armature,
camera, or animation.

Preview:

`prototype/test_output/chibi_base_mesh_accurig_input_v3_preview/`

The v1 and v2 upload packages are marked invalid because their Mirror order
was incorrect.
